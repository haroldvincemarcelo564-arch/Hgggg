# 🚀 Nebula Client - Quick Start Guide

## 30-Second Installation

### Step 1: Download
👉 [Download JAR](https://github.com/haroldvincemarcelo564-arch/Hgggg/releases)

### Step 2: Move to Mods Folder

**Windows:**
- Press `Win + R`
- Type: `%APPDATA%\.minecraft\mods`
- Drag JAR here

**Linux:**
```bash
mkdir -p ~/.minecraft/mods
mv nebula-client-1.0.0.jar ~/.minecraft/mods/
```

**macOS:**
```bash
mkdir -p ~/Library/Application\ Support/minecraft/mods
mv nebula-client-1.0.0.jar ~/Library/Application\ Support/minecraft/mods/
```

### Step 3: Launch
- Open Minecraft
- Select Fabric 1.21.1 profile
- Click Play
- Done! ✨

---

## Install Optimization Mods (Recommended)

For best performance, install these mods to your mods folder:

1. **Sodium** - https://modrinth.com/mod/sodium
2. **Lithium** - https://modrinth.com/mod/lithium
3. **Entity Culling** - https://modrinth.com/mod/entity-culling
4. **Starlight** - https://modrinth.com/mod/starlight

Then restart Minecraft.

## Troubleshooting

**Won't start?**
- Check Java 21: `java -version`
- JAR in correct mods folder?

**Low FPS?**
- Install Sodium + Lithium
- Lower render distance
